# Test results

Status: P0 passed; P1 native build/tests and still/dynamic project-model board-to-API runs passed. P2 has real MPP decode and RGA preprocessing stage measurements, but no end-to-end media optimization is accepted. ROI enter/leave/dwell events, occupancy, and cumulative-entry metrics passed synthetic and board-side checks. Same-model preprocessing comparisons are exploratory; one default-threshold detection difference appeared on one of six frames. Raw low-score output differences, tracker identity, labeled accuracy, and direct NPU-utilization validation remain open. Updated 2026-11-05.
