# Test results

Status: P0 passed; P1 native build/tests and still/dynamic project-model board-to-API runs passed. P2 now includes RK3576 FP/INT8 worker A/B, FIFO/latest queue-policy implementation and overload comparison, malformed-media/model failure probes, SQLite outage and bounded-write-failure recovery simulations, plus MPP/RGA stage measurements. P3 now has a monitored soak runner and looped deterministic-input smoke checks; the 24-hour run has not started. INT8 improved throughput on the single 10-FPS sample but is not promoted because calibration is small and no labels establish detection/event quality. Latest reduced p95 latency relative to FIFO under the measured queue-1 overload, with nearly identical processed-frame counts. No MPP/RGA end-to-end optimization is accepted. ROI enter/leave/dwell events, occupancy, and cumulative-entry metrics passed synthetic and board-side checks. Same-model preprocessing comparisons are exploratory; one default-threshold detection difference appeared on one of six frames. Raw low-score output differences, tracker identity, labeled accuracy, RTSP, actual filesystem-exhaustion/restart recovery and direct NPU-utilization validation remain open. Updated 2026-11-05.
