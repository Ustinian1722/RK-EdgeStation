YOLOv8n ONNX CPU vs RKNN RK3576 exploratory same-input comparison
Date: 2026-11-05

Scope and setup
- ONNX source: RKNN Model Zoo v2.0.0 optimized YOLOv8n graph, SHA-256 0c8716701f471067932b797eeb67c8e5db47c693c2557c881d7679ec12e21bc5.
- RKNN model: RK3576 fp/non-quantized export, SHA-256 2162e0cf6a71270c092353d94abb391ac111910ce178547ef80dd89b225dab0b.
- Board: KICKPI K7 / RK3576, RKNN Runtime 2.0.0b0, driver 0.9.7.
- ONNX Runtime CPU: 1.16.0 in the isolated Toolkit2 WSL environment.
- Both runtimes received the same saved post-letterbox RGB uint8 NHWC tensor. ONNX input was converted to float32, divided by 255, and transposed to NCHW.
- RKNN output tensor attributes report FP16; rknn_outputs_get(want_float=1) returned the dumped tensors as float32.
- Default confidence threshold 0.25; NMS threshold 0.45; class-aware greedy detection matching threshold IoU 0.50. A separate confidence sweep used 0.25, 0.34, 0.345, 0.35, 0.40, and 0.50 on the saved tensors.
- The board worker received a 16-frame repeated-still clip for each source image; only the first processed inference output from each run was captured and compared. No frame averaging was used. This is not a labeled accuracy test.

Raw output comparison
- The three box-regression tensors had cosine similarity 0.9999925-0.9999964 and range-normalized RMSE 0.000302-0.000672 across these six inputs.
- Class-score tensors differed more in low-score regions. RKNN class outputs had a minimum value of 0.001831 on all samples, while ONNX outputs included exact zeros.
- The ReduceSum score-sum tensors had mean absolute errors of 0.1455-0.1462. The observed class-score floor contributes to this gap; its exact runtime/compiler cause has not been isolated.
- At confidence 0.25, all six thresholded post-NMS detection sets matched. At confidence 0.345, the bus sample diverged: ONNX retained 4 detections and RKNN retained 5 (set-agreement F1 0.889); the extra RKNN detection had confidence 0.345215 versus 0.341804 in ONNX. The five vtest samples still matched across all six tested thresholds.
- Independent Python decoding was close to the C++ postprocessor. It matched all 5 bus detections at IoU 0.90 and most vtest detections; vtest frame 125 matched 8/9 at IoU 0.90 because one small box shifted by one pixel. Confidence differences among matched boxes were below 0.00000004. These pixel-sensitive differences reflect floating-point DFL/postprocess rounding and need consideration when setting an exact-box parity tolerance.

Limits
- Only six single-frame inputs were compared: five frames from one public vtest clip plus the Model Zoo bus still. The vtest frames were repeated only to run through the existing worker pipeline.
- No ground-truth labels were used. These results are limited to numerical and thresholded detection-set observations, not detector accuracy, model equivalence, or product acceptance.
- The confidence sweep already shows a bus detection-set difference at threshold 0.345. Low-score class and score-sum discrepancies need investigation on a larger representative set before accepting numerical alignment.
- Raw input/output dumps and model weights remain in ignored .work directories and are not committed.
